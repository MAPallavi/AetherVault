# Contributing to AetherVault

Thank you for your interest in contributing to AetherVault! We welcome issues, pull requests, and discussions.

## How to Contribute
1.  **Fork the Repository**: Clone your fork locally.
2.  **Create a Feature Branch**:
    ```bash
    git checkout -b feature/my-cool-idea
    ```
3.  **Implement & Test**: Write unit test cases and run checks:
    ```bash
    npm run build
    npm test
    ```
4.  **Submit a Pull Request**: Align your changes against the `main` branch.
