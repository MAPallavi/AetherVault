# AetherVault User Guide

Operational guide for users interacting with the vault.

## Basic Operations
1.  **Uploading Files**: Drag files directly into the file list view to start immediate encryption.
2.  **Shortcuts**: Use `F2` to rename, `Ctrl+C`/`Ctrl+V` to copy/paste, or `Shift+Delete` to purge files permanently.
3.  **Sharing**: Generate passcode-secured links or invite users to workspaces via the sharing panels.
4.  **AI Intelligence**: Query files semantically or review summaries in the preview sidebar.
