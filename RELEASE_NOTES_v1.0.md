# Release Notes - AetherVault v1.0.0 (RC1)

We are proud to announce the first Release Candidate of AetherVault!

## Release Highlights
*   **Zero-Knowledge Encrypted Stream Pipeline**: Dynamically encrypts incoming assets using AES-256 ciphers.
*   **AI Smart Assistant Integration**: Semantic search indexes, dynamic document classifiers, and file summaries.
*   **Enterprise Collaboration Settings**: Switch workspaces easily and manage invitations or file permissions.
*   **Unified Platform Health Probes**: `/api/health/liveness` and `/readiness` checks.

## Upgrade Guide
Update system environment settings:
```bash
# Set production node environment variables
NODE_ENV=production
```
